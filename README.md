# 🧱 Tile Layout Planner

Веб-инструмент для раскладки плитки на пол или стену.

## Возможности

- 🏠 Рисование комнаты любой формы (прямая, угол наружу, угол внутрь)
- 🧱 4 вида раскладки: прямая, поперечная, диагональ, со смещением
- 📐 Учёт шва, стартового угла, масштаба
- 💾 Сохранение/загрузка проектов в JSON
- 👁️ Наглядная визуализация: целые плитки зелёные, резаные оранжевые

## Как пользоваться

1. Нарисуйте контур комнаты (кнопка "Прямая", "Угол внутрь/наружу").
2. Замкните контур.
3. Переключитесь в "Режим плитки".
4. Задайте размеры плитки и шва.
5. Выберите тип раскладки.
6. Кликните по углу, чтобы выбрать стартовый угол.

## Технологии

- Чистый JavaScript (без фреймворков)
- HTML5 Canvas
- CSS3
